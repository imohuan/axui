## packages/cli/ - CLI 工具 (核心模块)

这是 shadcn-vue 最核心的部分，发布为 npm 包 `shadcn-vue`。

```
packages/cli/
├── scripts/
│   └── rimraf.js        # 清理脚本
├── src/
│   ├── commands/        # CLI 命令实现
│   │   ├── add.ts       # 添加组件命令
│   │   ├── apply.ts     # 应用配置命令
│   │   ├── build.ts     # 构建命令
│   │   ├── diff.ts      # 差异比较命令
│   │   ├── docs.ts      # 打开文档命令
│   │   ├── info.ts      # 项目信息命令
│   │   ├── init.ts      # 初始化命令 (最重要的命令)
│   │   ├── mcp.ts       # MCP 服务器命令
│   │   ├── migrate.ts   # 迁移命令
│   │   ├── search.ts    # 搜索组件命令
│   │   ├── view.ts      # 查看组件命令
│   │   └── registry/    # Registry 相关子命令
│   │       ├── build.ts # 构建 registry
│   │       └── mcp.ts   # MCP registry 操作
│   ├── icons/           # 图标库管理
│   ├── mcp/             # MCP 服务器实现
│   ├── migrations/      # 数据库/配置迁移逻辑
│   ├── preflights/      # 预检查 (项目初始化前的检查)
│   ├── preset/          # 预设 (preset) 系统
│   ├── registry/        # Registry API 客户端
│   ├── schema/          # Zod Schema 定义
│   ├── styles/          # 样式相关
│   ├── utils/           # 工具函数
│   ├── index.ts         # CLI 入口 (commander 程序)
│   └── tailwind.css     # 基础 Tailwind 动画和自定义 variant
├── test/                # 测试文件
├── package.json         # CLI 包定义
└── tsconfig.json
```

### CLI 命令一览

| 命令 | 功能 |
|------|------|
| `init` | 初始化项目，配置 Tailwind CSS + components.json |
| `add` | 添加组件到项目中 |
| `apply` | 应用已保存的配置 |
| `diff` | 比较本地组件与 registry 版本的差异 |
| `docs` | 在浏览器中打开组件文档 |
| `view` | 在终端中查看组件预览 |
| `search` | 搜索可用组件 |
| `migrate` | 项目迁移 (v3 -> v4 等) |
| `info` | 显示项目信息 |
| `build` | 构建 registry |
| `mcp` | 启动 MCP 服务器供 AI 使用 |

## templates/ - 项目模板

```
templates/
├── nuxt/
│   ├── app/      # Nuxt 应用模板
│   └── server/   # 服务端模板
├── vite/         # Vite Vue 模板
├── laravel/      # Laravel 模板
└── astro/        # Astro 模板
```

当用户运行 `npx shadcn-vue init --template nuxt` 时，CLI 会根据选择的模板创建项目结构。

# 03 - 组件实现模式

## 组件架构：两层分离

shadcn-vue 的组件分为两个层次：

### 第一层：Reka UI 原语层

所有交互逻辑由 Reka UI 提供，组件只是对 Reka UI 原语的**样式封装**。

例如，Accordion 组件：

```
Accordion.vue      ← 封装 AccordionRoot
AccordionItem.vue  ← 封装 AccordionItem
AccordionTrigger.vue ← 封装 AccordionTrigger
AccordionContent.vue ← 封装 AccordionContent
```

### 第二层：shadcn-vue 样式层

在 Reka UI 原语之上添加 Tailwind CSS 样式。

## 组件结构分析

### 简单组件: Card

Card 是纯展示组件，不依赖 Reka UI。

```vue
<!-- Card.vue -->
<script setup lang="ts">
import type { HTMLAttributes } from "vue"
import { cn } from "@/lib/utils"

const props = defineProps<{
  class?: HTMLAttributes["class"]
}>()
</script>

<template>
  <div
    data-slot="card"
    :class="cn(
      'bg-card text-card-foreground flex flex-col gap-6 rounded-xl border py-6 shadow-sm',
      props.class,
    )"
  >
    <slot />
  </div>
</template>
```

Card 的 index.ts 导出：

```typescript
export { default as Card } from "./Card.vue"
export { default as CardAction } from "./CardAction.vue"
export { default as CardContent } from "./CardContent.vue"
export { default as CardDescription } from "./CardDescription.vue"
export { default as CardFooter } from "./CardFooter.vue"
export { default as CardHeader } from "./CardHeader.vue"
export { default as CardTitle } from "./CardTitle.vue"
```

**特点：**
- 每个子组件是独立的 .vue 文件
- 使用 `data-slot` 属性标记组件类型 (用于 style CSS 选择)
- 使用 CSS 变量 (如 `bg-card text-card-foreground`) 而不是硬编码颜色
- 通过 `cn()` 合并默认样式和用户传入的 class

### 复杂组件: Accordion (依赖 Reka UI)

```vue
<!-- Accordion.vue - 根组件 -->
<script setup lang="ts">
import type { AccordionRootEmits, AccordionRootProps } from "reka-ui"
import { AccordionRoot, useForwardPropsEmits } from "reka-ui"

const props = defineProps<AccordionRootProps>()
const emits = defineEmits<AccordionRootEmits>()

const forwarded = useForwardPropsEmits(props, emits)
</script>

<template>
  <AccordionRoot v-slot="slotProps" data-slot="accordion" v-bind="forwarded">
    <slot v-bind="slotProps" />
  </AccordionRoot>
</template>
```

```vue
<!-- AccordionContent.vue - 内容面板 -->
<script setup lang="ts">
import type { AccordionContentProps } from "reka-ui"
import type { HTMLAttributes } from "vue"
import { reactiveOmit } from "@vueuse/core"
import { AccordionContent } from "reka-ui"
import { cn } from "@/lib/utils"

const props = defineProps<AccordionContentProps & { class?: HTMLAttributes["class"] }>()
const delegatedProps = reactiveOmit(props, "class")
</script>

<template>
  <AccordionContent
    data-slot="accordion-content"
    v-bind="delegatedProps"
    class="data-[state=closed]:animate-accordion-up data-[state=open]:animate-accordion-down overflow-hidden text-sm"
  >
    <div :class="cn('pt-0 pb-4', props.class)">
      <slot />
    </div>
  </AccordionContent>
</template>
```

**关键模式：**

1. **Props 透传**: 使用 `useForwardPropsEmits` 将组件的 props/emits 转发给 Reka UI 原语
2. **Props 过滤**: 使用 `reactiveOmit(props, "class")` 将 `class` 从透传 props 中移除，单独处理
3. **v-slot 透传**: 使用 `v-slot="slotProps"` 将 Reka UI 的 slot props 暴露给用户
4. **data-slot 标记**: 每个组件都有 `data-slot="xxx"` 属性，供 CSS 选择器使用

### 交互组件: Dialog

Dialog 组件展示了更复杂的模式：

```
Dialog.vue          ← 封装 DialogRoot (控制 open/close 状态)
DialogTrigger.vue   ← 封装 DialogTrigger (触发按钮)
DialogOverlay.vue   ← 封装 DialogOverlay (遮罩层)
DialogContent.vue   ← 封装 DialogContent (内容区域)
DialogHeader.vue    ← 纯布局组件 (标题区域)
DialogFooter.vue    ← 纯布局组件 (底部操作区)
DialogTitle.vue     ← 封装 DialogTitle (可访问标题)
DialogDescription.vue ← 封装 DialogDescription (可访问描述)
DialogClose.vue     ← 封装 DialogClose (关闭按钮)
DialogScrollContent.vue ← 封装 DialogScrollContent (可滚动内容)
```

### 复合组件: Button

```vue
<!-- Button.vue -->
<script setup lang="ts">
import type { PrimitiveProps } from "reka-ui"
import type { HTMLAttributes } from "vue"
import type { ButtonVariants } from "."
import { Primitive } from "reka-ui"
import { cn } from "@/lib/utils"
import { buttonVariants } from "."

interface Props extends PrimitiveProps {
  variant?: ButtonVariants["variant"]
  size?: ButtonVariants["size"]
  class?: HTMLAttributes["class"]
}

const props = withDefaults(defineProps<Props>(), {
  as: "button",
})
</script>

<template>
  <Primitive
    data-slot="button"
    :data-variant="variant"
    :data-size="size"
    :as="as"
    :as-child="asChild"
    :class="cn(buttonVariants({ variant, size }), props.class)"
  >
    <slot />
  </Primitive>
</template>
```

Button 的 index.ts 展示了 **class-variance-authority (cva)** 的使用：

```typescript
export const buttonVariants = cva(
  "inline-flex items-center justify-center gap-2 whitespace-nowrap rounded-md text-sm font-medium transition-all disabled:pointer-events-none disabled:opacity-50 [&_svg]:pointer-events-none [&_svg:not([class*='size-'])]:size-4 shrink-0 [&_svg]:shrink-0 outline-none focus-visible:border-ring focus-visible:ring-ring/50 focus-visible:ring-3 aria-invalid:ring-destructive/20 dark:aria-invalid:ring-destructive/40 aria-invalid:border-destructive",
  {
    variants: {
      variant: {
        default: "bg-primary text-primary-foreground hover:bg-primary/90",
        destructive: "bg-destructive text-white hover:bg-destructive/90 ...",
        outline: "border bg-background shadow-xs hover:bg-accent ...",
        secondary: "bg-secondary text-secondary-foreground hover:bg-secondary/80",
        ghost: "hover:bg-accent hover:text-accent-foreground ...",
        link: "text-primary underline-offset-4 hover:underline",
      },
      size: {
        default: "h-9 px-4 py-2 has-[>svg]:px-3",
        xs: "h-6 gap-1 rounded-md px-2 text-xs ...",
        sm: "h-8 rounded-md gap-1.5 px-3 ...",
        lg: "h-10 rounded-md px-6 ...",
        icon: "size-9",
      },
    },
    defaultVariants: {
      variant: "default",
      size: "default",
    },
  },
)
```

## 核心设计模式总结

### 1. Primitive 组件模式

Button 不是用 `<button>` 标签，而是用 Reka UI 的 `<Primitive>` 组件。

Primitive 优势：
- `as` prop: 可以渲染为 `<button>`, `<a>`, `<div>` 等任意元素
- `asChild`: 可以将自己的 props 传递给子元素（用于组合）
- 内置可访问性支持

### 2. data-slot 命名规范

每个组件都有唯一的 `data-slot` 属性值，用于：
- CSS 选择器的锚点 (style CSS 中 `.cn-xxx` 类 + `data-slot`)
- 调试时的组件识别
- 自动化工具 (如 MCP) 识别组件

### 3. cn() 工具函数

```typescript
// apps/v4/registry/new-york-v4/lib/utils.ts
import { type ClassValue, clsx } from "clsx"
import { twMerge } from "tailwind-merge"

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs))
}
```

组合 `clsx` (类名合并) 和 `tailwind-merge` (Tailwind 类名冲突解决)。

### 4. index.ts 导出模式

每个组件文件夹有一个 `index.ts`，导出所有子组件：

```typescript
export { default as Accordion } from "./Accordion.vue"
export { default as AccordionContent } from "./AccordionContent.vue"
export { default as AccordionItem } from "./AccordionItem.vue"
export { default as AccordionTrigger } from "./AccordionTrigger.vue"
```

用户使用时：

```vue
<script setup>
import { Accordion, AccordionContent, AccordionItem, AccordionTrigger } from "@/components/ui/accordion"
</script>
```

### 5. cva 变体模式 (用于 Button 等需要多外观的组件)

`class-variance-authority` 提供了类型安全的变体 API：

- `variants`: 定义多个变体维度 (variant, size)
- `defaultVariants`: 默认变体值
- 类型推导: `VariantProps<typeof buttonVariants>` 自动生成变体类型

不仅用在组件内部，也暴露给外部：

```typescript
export const buttonVariants = cva(...)
export type ButtonVariants = VariantProps<typeof buttonVariants>
```

其他组件可以直接复用 buttonVariants。

### 6. 组件注册表模式

每个组件在 `_registry.ts` 中声明其依赖和文件：

```typescript
export const ui: Registry["items"] = [
  {
    name: "accordion",
    type: "registry:ui",
    dependencies: ["reka-ui", "@vueuse/core"],
    files: [
      { path: "ui/accordion/Accordion.vue", type: "registry:ui" },
      { path: "ui/accordion/AccordionContent.vue", type: "registry:ui" },
      { path: "ui/accordion/AccordionItem.vue", type: "registry:ui" },
      { path: "ui/accordion/AccordionTrigger.vue", type: "registry:ui" },
      { path: "ui/accordion/index.ts", type: "registry:ui" },
    ],
  },
  // ...
]
```

CLI 通过这个注册表知道：
- 组件依赖哪些 npm 包
- 组件包含哪些文件
- 什么时候需要安装额外依赖

### 7. style CSS 分离

组件的**基础结构**通过 Tailwind 类写在 `.vue` 文件中，组件的**风格差异**通过独立的 CSS 文件 (style-*.css) 覆盖。

基础组件类与 style CSS 的对应关系：

| data-slot | style CSS 类 | 覆盖内容 |
|-----------|-------------|---------|
| accordion-trigger | .cn-accordion-trigger | padding, 圆角, hover 效果 |
| alert | .cn-alert | padding, border, gap |
| avatar | .cn-avatar | 尺寸, 圆角 |

`cn-` 前缀表示 "component"。

### 8. 透明动画

动画通过 Tailwind CSS 自定义 keyframes 和 animate 实现：

```css
/* 在 tailwind.css 中定义 */
@theme inline {
  @keyframes accordion-down {
    from { height: 0; }
    to { height: var(--reka-accordion-content-height); }
  }
}

/* 在组件中使用 */
class="data-[state=closed]:animate-accordion-up data-[state=open]:animate-accordion-down"
```

# 06 - 核心依赖与工具链

## 运行时依赖

### UI 原语库: Reka UI

```
reka-ui: ^2.10.1
```

Reka UI 是 Radix Vue 的继任者，提供无样式的可访问 UI 原语。

在 shadcn-vue 中的角色：
- 提供所有交互组件的底层实现
- DialogRoot, AccordionRoot, PopoverRoot 等容器组件
- useForwardPropsEmits: 转发 props/emits 到 Reka UI 组件
- Primitive: 通用包装组件，支持 as/asChild

shadcn-vue 中几乎所有交互组件都是 Reka UI 组件的样式封装：

| shadcn-vue 组件 | Reka UI 原语 |
|----------------|-------------|
| Accordion | AccordionRoot |
| Dialog | DialogRoot |
| Popover | PopoverRoot |
| Select | SelectRoot |
| Tooltip | TooltipRoot |
| Tabs | TabsRoot |
| ... | ... |

## 关键工具深入

### class-variance-authority (cva)

cva 是 shadcn-vue 组件变体系统的核心：

```typescript
const buttonVariants = cva(
  // 基础类
  "inline-flex items-center justify-center ...",
  {
    variants: {
      variant: { default: "...", destructive: "..." },
      size: { default: "...", sm: "...", lg: "..." }
    },
    defaultVariants: { variant: "default", size: "default" }
  }
)
```

使用 cva 的优势：
- 类型安全: TypeScript 自动推导变体类型
- 可组合: 多个变体维度自动组合
- 可导出: 类型暴露给其他组件复用
- 默认值: 不传变体时使用默认样式

### tailwind-merge + clsx → cn()

```typescript
export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs))
}
```

- clsx: 处理条件类名 (字符串、对象、数组)
- tailwind-merge: 解决 Tailwind 类名冲突 (后面的覆盖前面的同属性类)

### @vueuse/core 的 reactiveOmit

在组件中用于过滤 class prop：

```typescript
const props = defineProps<AccordionContentProps & { class?: HTMLAttributes["class"] }>()
const delegatedProps = reactiveOmit(props, "class")
```

`reactiveOmit` 创建一个响应式对象，排除指定属性。这样 Reka UI 原语就不会收到 `class` prop。

### vue-metamorph

用于 Vue 代码的自动迁移和转换。在 shadcn-vue 中用于：
- v3 -> v4 的组件代码迁移
- 批量更新组件 API

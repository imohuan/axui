# 02 - 主题系统设计

## 设计系统四层架构

shadcn-vue 的设计系统分为四个独立的层：

```
Base (基础层) ──→ Style (风格层) ──→ Theme (主题层) ──→ 预设组合
```

### 第一层: Base (基础层)

Base 定义了底层 UI 原语。当前只有一个 base:

**reka**: 基于 Reka UI 库，提供所有无样式的基础交互组件原语。

Base 在 `apps/v4/registry/bases.ts` 中定义：

```typescript
export const BASES = [{
  name: "reka",
  type: "registry:style",
  title: "Reka UI",
  description: "Optimized for fast development, easy maintenance, and accessibility.",
  dependencies: ["reka-ui"],
}]
```

Base 决定了：
- 使用哪个底层 UI 库 (Reka UI 提供了 AccordionRoot, DialogRoot 等无样式原语)
- 有哪些组件可用 (基于该库的能力)

### 第二层: Style (风格层)

Style 控制组件的**视觉风格**（padding、圆角、间距等），不涉及颜色。

8 种风格定义在 `apps/v4/registry/styles.ts`：

| 风格名 | 标题 | 描述 |
|--------|------|------|
| vega | Vega | 经典 shadcn/ui 风格，干净、中性、熟悉 |
| nova | Nova | 紧凑布局，减少 padding 和 margin |
| maia | Maia | 柔和圆润，间距充足 |
| lyra | Lyra | 方正锐利，适合等宽字体 |
| mira | Mira | 超紧凑，适合密集界面 |
| luma | Luma | 流动、发光、玻璃质感 |
| sera | Sera | 编辑排版风格，注重文字 |
| rhea | Rhea | 最新 shadcn/ui 风格，精炼间距和现代默认值 |

每种风格有独立的 CSS 文件 (`apps/v4/registry/styles/style-*.css`)，例如 style-nova.css：

```css
.style-nova {
  /* Accordion 样式 */
  .cn-accordion-item {
    @apply not-last:border-b;
  }
  .cn-accordion-trigger {
    @apply rounded-lg py-2.5 text-left text-sm font-medium hover:underline ...;
  }
  
  /* Alert 样式 */
  .cn-alert {
    @apply grid gap-0.5 rounded-lg border px-2.5 py-2 ...;
  }
  
  /* Avatar 样式 */
  .cn-avatar {
    @apply size-8 rounded-full ...;
  }
  
  /* ... 更多组件样式 ... */
}
```

**风格覆盖机制**：每个风格 CSS 都通过 `.style-xxx` 选择器包裹，通过给 `<body>` 添加 `class="style-nova"` 来激活对应风格。style CSS 覆盖的是**基础组件类** (如 `.cn-accordion-trigger`)，改变 padding、圆角、间距等，但不改变颜色。

### 第三层: Theme (主题层)

Theme 控制**颜色方案**，包括亮色和暗色两种模式。

定义在 `apps/v4/registry/themes.ts`，约 30 个主题。每个主题定义一组 CSS 变量：

```typescript
{
  name: "neutral",
  type: "registry:theme",
  cssVars: {
    light: {
      "background": "oklch(1 0 0)",
      "foreground": "oklch(0.145 0 0)",
      "primary": "oklch(0.205 0 0)",
      "primary-foreground": "oklch(0.985 0 0)",
      "secondary": "oklch(0.97 0 0)",
      "muted": "oklch(0.97 0 0)",
      "accent": "oklch(0.97 0 0)",
      "destructive": "oklch(0.577 0.245 27.325)",
      "border": "oklch(0.922 0 0)",
      "radius": "0.625rem",
      "sidebar": "oklch(0.985 0 0)",
      // ... 约30个 CSS 变量
    },
    dark: {
      "background": "oklch(0.145 0 0)",
      "foreground": "oklch(0.985 0 0)",
      "primary": "oklch(0.922 0 0)",
      // ...
    }
  }
}
```

### 第四层: 预设组合 (Presets)

Preset 把 Base + Style + Theme + 字体 + 图标库绑定在一起，提供开箱即用的组合。

定义在 `apps/v4/registry/config.ts`：

```typescript
export const PRESETS = [
  {
    name: "reka-vega",
    base: "reka",
    style: "vega",
    baseColor: "neutral",
    theme: "neutral",
    iconLibrary: "lucide",
    font: "inter",
    fontHeading: "inherit",
    radius: "default",
  },
  {
    name: "reka-nova",
    base: "reka",
    style: "nova",
    baseColor: "neutral",
    theme: "neutral",
    iconLibrary: "hugeicons",
    font: "inter",
    // ...
  },
  // ... 共 8 个 preset
]
```

## 设计系统配置 Schema

完整的配置结构 (Zod)：

```typescript
designSystemConfigSchema = z.object({
  base: z.enum(["reka"]),                    // Base 层
  style: z.enum(["vega","nova",...]),        // 风格层
  iconLibrary: z.enum(["lucide","hugeicons",...]), // 图标库
  baseColor: z.enum(["neutral","stone",...]), // 基础色 (7种)
  theme: z.enum(["neutral","stone",...]),     // 主题 (~30种)
  chartColor: z.enum([...]).optional(),       // 图表颜色
  font: z.enum(["inter","geist-sans",...]),   // 正文字体
  fontHeading: z.enum(["inherit",...]),       // 标题字体
  item: z.string().optional(),               // 条目样式
  menuAccent: z.enum(["subtle","bold"]),      // 菜单强调
  menuColor: z.enum(["default","inverted",...]), // 菜单颜色
  radius: z.enum(["default","none","small","medium","large"]), // 圆角
  template: z.enum(["nuxt","vite","laravel","astro"]), // 模板
  pointer: z.boolean(),                       // 指针样式
})
```

## 颜色系统设计亮点

### CSS 变量命名规范

shadcn-vue 使用语义化的 CSS 变量名：

| 变量 | 用途 |
|------|------|
| `--background` | 页面背景 |
| `--foreground` | 主要文字颜色 |
| `--card` | 卡片背景 |
| `--card-foreground` | 卡片文字 |
| `--primary` | 主色调 |
| `--primary-foreground` | 主色调上的文字 |
| `--secondary` | 次要色调 |
| `--muted` | 弱化区域背景 |
| `--muted-foreground` | 弱化文字 |
| `--accent` | 强调色 |
| `--destructive` | 破坏性操作色 |
| `--border` | 边框色 |
| `--input` | 输入框边框色 |
| `--ring` | 焦点环颜色 |
| `--radius` | 圆角值 |
| `--sidebar` | 侧边栏背景 |
| `--sidebar-foreground` | 侧边栏文字 |
| `--sidebar-primary` | 侧边栏主色 |
| `--chart-1` ~ `--chart-5` | 图表颜色 1-5 |

### 使用 OKLCH 颜色空间

所有颜色值使用 OKLCH 而不是 HEX 或 RGB：

```css
--primary: oklch(0.205 0 0);
--destructive: oklch(0.577 0.245 27.325);
```

OKLCH 的优势：
- 感知均匀：数值变化对应视觉变化更一致
- 亮度和色相分离：方便做暗色主题
- 更广的色域：支持 P3 色域

### 多种颜色变量

base-colors.ts 定义了 7 种基础色：
- neutral (中性灰)
- stone (石灰)
- zinc (锌灰)
- mauve (紫灰)
- olive (橄榄灰)
- mist (雾灰)
- taupe (褐灰)

每种基础色都有独立的亮色/暗色方案。

此外还有约 30 种彩色主题：blue, emerald, fuchsia, green, indigo, lime, orange, pink, purple, red, rose, sky, teal, violet, yellow 等。

### 主题合并机制

当 baseColor + theme 合并时，先取 baseColor 的完整变量，再用 theme 的变量覆盖 primary、secondary、chart、sidebar 等：

```typescript
function buildRegistryTheme(config) {
  const lightVars = {
    ...baseColor.cssVars.light,  // 基础色定义全部变量
    ...theme.cssVars.light,      // 主题只覆盖颜色相关变量
  }
  // 暗色同理
}
```

### 圆角系统

5 档圆角：

| 名称 | 值 |
|------|-----|
| none | 0 |
| small | 0.45rem |
| default | "" (空，用 CSS 变量默认) |
| medium | 0.625rem |
| large | 0.875rem |

### 菜单颜色系统

菜单有 4 种颜色模式：

| 值 | 标签 |
|----|------|
| default | 默认 / 实色 |
| default-translucent | 默认 / 半透明 |
| inverted | 反转 / 实色 |
| inverted-translucent | 反转 / 半透明 |

## 字体系统

在 `apps/v4/registry/fonts.ts` 中定义了约 24 种字体：

- **Sans**: Inter, Geist Sans, Noto Sans, Figtree, Roboto, DM Sans, Public Sans, Outfit, Manrope, Space Grotesk, Montserrat, IBM Plex Sans, Source Sans 3, Instrument Sans, Nunito Sans, Raleway
- **Mono**: JetBrains Mono, Geist Mono
- **Serif**: Playfair Display, Noto Serif, Roboto Slab, Merriweather, Lora
- **Display**: Oxanium

每种字体都定义了 `provider: "google"`，通过 Google Fonts 加载。

支持独立设置正文和标题字体，当 `fontHeading === font` 时自动折叠为 "inherit"。

## 图标库系统

支持 5 种图标库：

| 名称 | npm 包 |
|------|--------|
| lucide | @lucide/vue |
| hugeicons | @hugeicons/vue, @hugeicons/core-free-icons |
| phosphor | @phosphor-icons/vue |
| tabler | @tabler/icons-vue |
| remixicon | @remixicon/vue |

每种图标库在 `apps/v4/registry/icons/` 下有对应的加载器和类型定义。

## Tailwind CSS v4 集成

### @theme inline 块

在 `packages/cli/src/tailwind.css` 中定义：

```css
@theme inline {
  @keyframes accordion-down { /* ... */ }
  @keyframes accordion-up { /* ... */ }
}
```

### 自定义 variant

```css
@custom-variant data-open {
  &:where([data-state="open"]),
  &:where([data-open]:not([data-open="false"])) {
    @slot;
  }
}
@custom-variant data-closed { /* ... */ }
@custom-variant data-checked { /* ... */ }
@custom-variant data-unchecked { /* ... */ }
```

这些自定义 variant 允许在组件中使用 `data-open:animate-xxx` 这样的语法。

### 项目初始化时注入的 CSS

CLI `init` 命令会在用户项目中创建：

```css
@import "tw-animate-css";
@import "shadcn-vue/tailwind.css";

@layer base {
  * {
    @apply border-border outline-ring/50;
  }
  body {
    @apply bg-background text-foreground font-sans;
  }
}
```

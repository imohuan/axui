# 07 - 模板系统

## 模板概述

shadcn-vue 的 CLI 支持通过模板初始化不同类型的项目。模板定义了项目的基础结构，让 shadcn-vue 的组件可以无缝集成到不同的 Vue 项目类型中。

## 支持的模板类型

| 模板 | 框架 | 适用场景 |
|------|------|---------|
| nuxt | Nuxt 3/4 | Nuxt 全栈应用 |
| vite | Vite + Vue 3 | 纯 Vue SPA |
| laravel | Laravel + Vue | Laravel 全栈 (Inertia) |
| astro | Astro + Vue | Astro 静态站点 |

配置在 config.ts 中：

```typescript
template: z.enum(["nuxt", "vite", "laravel", "astro"]).default("nuxt")
```

## 模板在 CLI 中的使用

在 `init` 命令中，模板参数决定了：

1. **创建项目时的文件结构**
2. **Tailwind CSS 的配置方式**
3. **路径别名的默认值**
4. **CSS 文件的位置**

### Nuxt 模板

```
templates/nuxt/
├── app/
│   ├── app.vue
│   ├── assets/
│   │   └── css/
│   │       └── tailwind.css
│   └── ...
└── server/
    └── ...
```

特点：
- 使用 `@nuxtjs/tailwindcss` 模块
- Tailwind 配置在 `nuxt.config.ts` 中
- CSS 文件在 `assets/css/` 下
- 路径别名 `@/` 指向项目根目录

### Vite 模板

```
templates/vite/
```

特点：
- 使用 `@tailwindcss/vite` 插件
- Tailwind 配置在 `tailwind.config.ts`
- CSS 在 `src/assets/` 或 `src/styles/`
- 路径别名 `@/` 指向 `src/`

### Laravel 模板

```
templates/laravel/
```

特点：
- 适配 Laravel + Inertia.js + Vue 的项目结构
- Tailwind 配置在 `tailwind.config.js`
- 资源文件在 `resources/` 下

### Astro 模板

```
templates/astro/
```

特点：
- 适配 Astro + Vue 集成
- Tailwind 通过 Astro 集成配置

## 项目检测机制

`init` 命令会先检测项目类型，再选择合适的模板：

```typescript
// packages/cli/src/utils/get-project-info.ts

async function getProjectInfo(cwd: string) {
  // 检查 package.json 中的依赖
  // 检查 nuxt.config.ts 是否存在 → Nuxt 项目
  // 检查 vite.config.ts 是否存在 → Vite 项目
  // 检查 composer.json 是否存在 → Laravel 项目
  // 检查 astro.config.mjs 是否存在 → Astro 项目
}
```

## 创建项目的完整流程

```typescript
// packages/cli/src/utils/create-project.ts

export const TEMPLATES = {
  nuxt: { /* nuxt 模板配置 */ },
  vite: { /* vite 模板配置 */ },
  laravel: { /* laravel 模板配置 */ },
  astro: { /* astro 模板配置 */ },
}

async function createProject(options) {
  // 1. 根据模板选择对应的文件结构
  // 2. 创建目录
  // 3. 写入 package.json
  // 4. 写入框架配置文件 (nuxt.config.ts / vite.config.ts / ...)
  // 5. 写入 TypeScript 配置
  // 6. 写入 Tailwind CSS 配置和入口文件
  // 7. 写入 utils.ts (cn 函数)
  // 8. 创建初始 app 文件
  // 9. 安装依赖
}
```

## 每个模板的通用产出

无论选择哪个模板，init 后都会获得：

1. **components.json** - shadcn-vue 配置文件
2. **utils.ts** - cn() 工具函数
3. **Tailwind CSS 配置** - 包含 shadcn-vue 需要的 @theme 和 @custom-variant
4. **tailwind.css** (或等效) - 包含基础样式：
   ```css
   @import "tw-animate-css";
   @import "shadcn-vue/tailwind.css";
   
   @layer base {
     * {
       @apply border-border outline-ring/50;
     }
     body {
       @apply bg-background text-foreground;
     }
   }
   ```
5. **基础依赖**已安装：
   - shadcn-vue (CLI 本身)
   - reka-ui
   - class-variance-authority
   - tailwind-merge
   - clsx
   - tw-animate-css
   - 以及根据预设选择的图标库

## Nuxt 模块 (packages/module)

与模板不同，Nuxt 模块 `shadcn-nuxt` 是一个独立的 npm 包，用于简化 Nuxt 项目中的 shadcn-vue 集成。

```typescript
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['shadcn-nuxt']
})
```

模块自动处理：
- Reka UI 的 Nuxt 集成
- Tailwind CSS 的配置
- 颜色模式 (通过 @nuxtjs/color-mode)
- 自动导入组件

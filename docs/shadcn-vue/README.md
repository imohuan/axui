## 项目概要

shadcn-vue 是 shadcn/ui 的 Vue 生态移植版本，由 unovue 组织维护。

版本: 2.8.1
仓库: https://github.com/unovue/shadcn-vue
包管理器: pnpm (>=9.6.0)
Node: ESM 模块

## 分析目标

本文档系列对 shadcn-vue 项目进行全面分析，涵盖其架构设计、主题系统、组件实现方式、CLI 工具、构建流程等各方面，旨在为开发自己的组件库提供参考。

# 00 - 项目总览

## 什么是 shadcn-vue

shadcn-vue 是 shadcn/ui 在 Vue 生态中的移植版本。它不是传统的 npm 组件库——不通过 `npm install` 安装后 `import` 使用，而是通过 CLI 工具将组件源代码**直接复制到你的项目里**。

核心理念: "你拥有这些代码"——组件被复制到你的项目中后，你可以完全自由地修改它们，不依赖任何中间层。

## 工作原理 (3 个核心角色)

### 1. CLI 工具 (packages/cli)
- 提供 `init`、`add`、`diff`、`build`、`search`、`view` 等命令
- `init`: 初始化项目，配置 Tailwind CSS、创建 `components.json`
- `add`: 从 registry 下载组件到用户项目
- `diff`: 比较本地组件与远程 registry 的差异
- `mcp`: 启动 MCP 服务器，供 AI 工具使用

### 2. Registry (apps/v4/registry)
- 定义所有可用的组件、样式、主题
- 分为 base 层和 style 层
- Base: reka (基于 Reka UI)
- Style: vega, nova, maia, lyra, mira, luma, sera, rhea (8 种风格)

### 3. 文档网站 (apps/v4)
- 基于 Nuxt 4 + Nuxt Content
- 展示所有组件和示例
- 提供 Design System Picker (设计系统配置器)
- 部署在 Cloudflare (使用 Wrangler)

## 核心设计思想

### "Copy-Paste" 模式
组件不作为 npm 依赖发布，而是被 CLI 复制到项目中。优势:
- 完全控制组件的代码
- 可以随意定制修改
- 不会因为组件库更新导致意外破坏
- 组件代码即是自己项目的代码

### 分层架构
- Base 层: 定义底层 UI 原语 (如 Reka UI 的各种 Root/Trigger/Content)
- Style 层: 定义 CSS 视觉样式 (调整 padding、圆角、颜色等)
- Theme 层: 定义颜色主题 (亮色/暗色方案)

### CSS 优先
- 所有样式通过 Tailwind CSS 实现
- 使用 CSS 变量进行主题切换
- 动画也用 CSS 定义
- 少量自定义 CSS (style-*.css) 用于风格差异

## 技术栈

| 技术 | 用途 |
|------|------|
| Vue 3.5+ | 前端框架 |
| Reka UI | 无样式 UI 原语库 (Radix Vue 的继任者) |
| Tailwind CSS v4 | CSS 框架 |
| class-variance-authority | 组件变体管理 |
| tailwind-merge + clsx | 类名合并 |
| Nuxt 4 | 文档站点框架 |
| pnpm | 包管理器 |
| Vitest | 测试框架 |
| TypeScript | 类型系统 |
| Commander.js | CLI 命令解析 |
| Zod | Schema 验证 |

## shadcn-vue vs 传统组件库

| 维度 | 传统组件库 (如 Element Plus) | shadcn-vue |
|------|-----|------------|
| 安装方式 | npm install | npx shadcn-vue add |
| 代码位置 | node_modules | 你的源码目录 |
| 样式修改 | 通过 props / CSS 变量 | 直接改组件代码 |
| 更新方式 | 升级 npm 包版本 | CLI diff + 手动合并 |
| 按需引入 | tree-shaking | 只添加你需要的组件 |
| 定制深度 | 有限 (受 API 约束) | 无限 (你就是作者) |
| 学习成本 | 学习 API | 直接看源码 |
